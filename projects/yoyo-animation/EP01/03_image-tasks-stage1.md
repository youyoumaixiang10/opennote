# EP01 出图任务包 · 阶段 1：风格测试 + 角色定稿

> **用途**：确定全系列画风，定稿两个主角。这一步定下来后，后面所有集都复用。
> **共 5 张图**。下面每个任务都可以原样复制给 ChatGPT。

## 使用说明（给家长）

1. 在 ChatGPT 里**新建一个对话**，专门用于本系列出图（建议命名「攸攸动画 · 美术」）
2. 先发送 **【T0 风格锁定】**，让 ChatGPT 记住规则（它不需要出图）
3. 依次发送 T1 → T2 → T3 → T4 → T5，**每次发一个任务**，等出图后再发下一个
4. 某张不满意，可以在同一对话里说「请按原任务重新生成，注意：……」，不用从头开始
5. 把 5 张图下载下来，上传到仓库 `projects/yoyo-animation/EP01/assets/incoming/stage1/`，或直接发给我
6. 我会逐张对照验收清单给出评审意见和定稿建议，**由你最终确认画风和角色**

## 【T0 风格锁定】（先发这一段）

```
我们要为一部原创儿童绘本动画短片制作一系列画面素材。接下来我会一张一张地给你出图任务，请在整个对话中始终遵守以下规则，除非我在单个任务里另行说明。

【作品】
原创儿童绘本动画《月亮把银色送给了谁？》，观众是 2 岁多的孩子。主角是一个约 2 岁的中国小女孩「攸攸」和一只小白兔。故事发生在月光下的家庭小花园。

【画风：月夜水彩绘本】
- 传统透明水彩画在冷压水彩纸上，纸张颗粒清晰可见
- 天空用湿画法柔和晕染，草地和树皮用干笔笔触
- 少量轻柔、断续的彩色铅笔线条，只用来勾勒角色轮廓和细小细节，不描黑色粗边
- 最亮的地方是「留白」的纸色，月光 = 留白
- 构图疏朗，每个画面只有一个视觉焦点，留有呼吸空间
- 有高级感的独立绘本插画气质，安静、温柔、诗意

【色板】
夜空靛蓝 #233457、暮色蓝 #3E5580、雾紫 #6E6D94、夜草青绿 #34504B、月下草绿 #5F7E72、树影墨绿 #1E3433、池水深蓝 #1A2B45、月光银白 #F2F4F1、冷银灰 #C3CED3、攸攸姜黄 #D3A04A、豆沙红 #B66A5C、兔毛暖白 #E4DACA、兔毛阴影灰紫 #9C9AAE。
夜色是「有颜色的深」，暗部里能透出蓝、紫、绿，不要大面积纯黑。

【光照】
- 唯一主光源是月亮，月亮始终在画面左上方（或画外左上方），光从左上前方照来，阴影朝右下、右后方
- 「月光银白」只用在月亮本身和当前画面要被观察的对象上，它必须是画面里最亮的地方
- 其他所有东西（包括小白兔）都不能比被观察的对象更亮

【禁止】
高饱和糖果色、大眼萌系、浓密睫毛、3D 渲染感、塑料光泽、霓虹发光、镜头光晕、密集粒子特效、描黑粗边、扁平矢量风、照片写实风、画面中出现任何文字或水印。

请回复「已了解」，暂时不要出图。
```

## 【T1 风格测试 A：月夜水彩绘本】（推荐方向）

```
任务 T1｜风格测试 A｜横版 1536×1024

请严格按照对话开头的【画风：月夜水彩绘本】【色板】【光照】【禁止】规则，画一张风格测试画面。这张图用于确定整部动画的画风。

【画面】月光下花园里的小池塘，中景。
- 画面中下部是一片安静的深蓝色池塘，水面平静，水中倒映着一个圆圆的月亮（倒影位于池塘左侧偏中，是画面中最亮的元素，用留白表现）
- 月亮本身在画面外左上方，不出现在画面里
- 池塘边缘有几丛芦苇，水面上有两三片睡莲叶，颜色深而安静
- 画面左下前景是一小块草地岸边，一个约 2 岁的中国小女孩和一只小白兔并排蹲在岸边（离水边还有一小步距离），背对镜头偏 3/4 侧面，正低头看着水里的月亮倒影
  - 小女孩：圆脸，齐耳深棕色短发，头顶扎一个小揪揪（姜黄色发绳），穿姜黄色长袖家居服和长裤，脚穿豆沙红软底小布鞋，约 3.5 头身，短手短腿
  - 小白兔：暖奶白色，圆润梨形身体，蹲着时头顶到小女孩肩膀，脖子上围着豆沙红色针织小围巾，兔子自己的右耳耳尖柔软地向前折下一小段，左耳直立
  - 两个角色在画面中较小（约占画面高度的 1/4），是画面的次要元素；月亮倒影才是视觉焦点
- 背景远处是雾紫色的树丛剪影，上方是靛蓝色夜空

【重点】
- 月亮倒影是唯一的最亮点，小白兔的白要明显暗于倒影（受光面暖白，阴影偏灰紫）
- 水彩纸纹和透明叠色要清楚可见
- 整体安静、诗意，不要可爱化过度

无文字，无边框。
```

## 【T3 角色设定图：攸攸】

```
任务 T3｜角色设定图：攸攸｜横版 1536×1024

请按对话开头的【画风：月夜水彩绘本】，为主角「攸攸」画一张角色设定图（character turnaround sheet）。这张图之后会作为所有画面中攸攸形象的唯一参考，请务必画得清楚、一致。

【背景】干净的浅暖白水彩纸，不画场景，柔和的日间中性光（这张是设定图，不用夜景光），确保颜色准确。

【角色设定】
- 原创绘本角色，约 2 岁的中国小女孩，不像任何真实儿童或已有卡通形象
- 比例：约 3.5 头身；圆脸、肉肉的脸颊；短手短腿，小肚子微圆；站姿略外八、重心靠前
- 发型：齐耳的深棕近黑短发，有自然的蓬松感；头顶扎一个小揪揪，用姜黄色小发绳扎起（这是角色最重要的剪影标志）
- 眼睛：小而亮的深棕色圆眼睛，各有一个小白色高光；眼睛约占脸宽的 1/6，不是大眼睛，没有睫毛
- 眉毛：淡淡的、短短的、略粗的小眉毛
- 鼻子：一个小小的弧线；嘴巴：小
- 脸颊：淡淡的水彩腮红晕染，不是圆形贴纸红晕
- 服装：姜黄色（#D3A04A）棉质长袖上衣和长裤，像柔软的家居服；上衣有奶白色小圆翻领；脚穿豆沙红（#B66A5C）软底小布鞋

【排版】
上排从左到右：正面全身、3/4 侧面全身、正侧面全身、背面全身（四个视图大小一致，站在同一条地平线上，姿势自然放松）
下排：三个头部特写表情——①好奇（眉毛微抬，嘴巴小小地合着，头微微前倾）②惊喜（嘴巴张成小圆「o」形，眼睛亮亮的）③开心（眯眼笑，脸颊鼓起）
右下角：小揪揪发绳的小细节图、小布鞋的小细节图

整体温柔自然、有灵气、有好奇心，不要过度可爱化。无文字标注，无水印。
```

## 阶段 1 回传后，我会怎么评审

| 维度 | 检查点 |
|---|---|
| 画风 A vs B | 哪个更能表现「光」？夜色是否有层次？在手机/平板屏幕上看是否太暗？哪个更适合做分层动画？ |
| 攸攸 | 小揪揪剪影是否清楚；眼睛是否克制（非大眼萌系）；是否像 2 岁（而不是 4–5 岁）；表情是否自然 |
| 小白兔 | 折耳是否在所有视图中一致；白色是否不刺眼；是否和攸攸风格统一 |
| 系列化 | 剪影辨识度（缩小到很小也能认出谁是谁）；服装与配色是否适合以后换季、换场景 |

**需要你确认的事项**：①选 A 还是 B（或「A 的方向 + 某些调整」）；②攸攸和小白兔的形象是否定稿。确认后我会把阶段 2 的任务包调整到定稿状态，再交给你出图。
