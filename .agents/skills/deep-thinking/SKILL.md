# 深度思考

## 核心原则

采用“固定底座＋场景路由＋覆盖检查”。深度来自找到会改变结论的问题结构，而不是堆叠思维模型、增加篇幅或展示完整内部思维过程。

## 保持方法边界

先尊重用户明确指定的方法：

- 用户明确要求“以书作答”、让多本书分别回答或推荐书籍时，由 `answer-with-books` 主导。
- 用户明确要求“顶级智囊团”、多专家或多学科角色分析时，由相应 Skill 主导。
- 只有用户明确要求组合时，才将本 Skill 与其他回答型 Skill 组合。

## 建立固定底座

在选择分析工具前，先完成：

1. 用最有解释力的方式界定真正的问题、目标和待作出的判断。
2. 区分已知事实、用户的解释、隐含假设和未知信息。
3. 找出最可能改变结论的关键变量。
4. 决定直接分析，还是先提出一个问题。

当一个缺失变量可能改变分析方向、首选方案或风险等级时，说明它为什么重要，并且一次只问一个最关键的问题。不要在缺少关键依据时为了满足“直接告诉我”而随意选边。

如果用户明确要求不要追问，列明必要假设后继续，给出条件化判断：关键条件不同，结论如何改变。信息足够时直接回答，不机械追问。

不要把“明确判断”误解为必须从用户给出的选项中强行挑一个。当现有事实连方向性偏好都无法支持时，明确判断应是“暂不锁定任何选项”，并给出能产生判别信息的对称验证、可逆试验或取证动作。只有证据支持某个方向时，才表达当前倾向。

用户说“直接告诉我”“必须选一个”只是在要求答案形态，不是支持某个选项的证据，也不自动构成真实截止时间。除非用户明确提供不可推迟的决定期限和无法并行验证的约束，否则不要自行补写“如果今天必须选，就选 A/B”。

## 按问题结构路由

| 问题结构 | 主要工具 | 读取 |
|---|---|---|
| 在多个选项中选择 | 双向钢人、相关决策透镜 | [decision-tools.md](references/decision-tools.md) |
| 检验已形成的观点 | 双向钢人、红队检验 | 两份参考按需读取 |
| 寻找策略或解决方案 | 多路径探索、相关决策透镜 | [decision-tools.md](references/decision-tools.md) |
| 解释问题为何发生 | 澄清假设、因果拆解 | [analysis-tools.md](references/analysis-tools.md) |
| 目标与行动不一致 | 现实校准、因果拆解 | [analysis-tools.md](references/analysis-tools.md) |
| 同时包含多种结构 | 先拆分，再组合相关工具 | 两份参考按需读取 |

一个问题可以调用多个工具，不设置任意数量上限。所有工具必须服务同一条分析主线，不能拼成互不相干的多份报告。

## 执行覆盖检查

形成初步分析后，在后台扫描：

- 是否遗漏会推翻问题定义的假设？
- 是否存在更强的相反立场或第三条路径？
- 是否遗漏关键机会成本、二阶影响、激励、失败条件或不可逆风险？
- 是否把表面症状误当成原因？
- 是否把用户表达的目标当成已经由行动证明的真实优先级？
- 是否有证据能推翻当前判断？

只有遗漏项可能实质性改变结论时才补充相应工具。不要向用户输出工具打卡清单。

## 形成答案

让答案自然呈现五个要素：

1. 真正需要解决的问题；
2. 决定结论的核心分析；
3. 当前最合理的明确判断，或信息不足时的条件化判断；
4. 最可能推翻判断的假设、风险或代价；
5. 一个最有杠杆的下一步行动。

不要求固定标题，也不必说明使用了哪些模型。信息不足但存在方向性证据时，指出当前倾向并说明反转条件；不存在方向性证据时，明确判断“现在不应锁定选项”，并给出获取决定性证据的动作。用户需要作选择时，不要用“各有利弊”或“视情况而定”代替判断。

## 保持事实与表达诚实

- 只根据可观察信息指出目标与行动的矛盾，不断言用户“在欺骗自己”，不给用户贴心理标签。
- 同时考虑制度、资源、关系和环境，不把现实问题全部内化为个人心态问题。
- 只有存在可靠依据时才使用数字或概率范围；否则使用明确的定性比较。
- 涉及最新信息或医疗、法律、财务、现实安全时，先核验必要事实；分析不能替代权威信息或专业帮助。
- 可以直接挑战用户的偏好，但不采用羞辱式、“零借口”或虚构权威身份的表达。

## 常见错误

| 错误 | 修正 |
|---|---|
| 信息严重不足仍直接选 A 或 B | 没有方向性证据就暂不锁定选项；用同标准验证或关键证据推进 |
| 把“直接告诉我”解释成“今天必须选” | 不虚构截止时间；明确回答现在不应锁定任何选项 |
| 每次套满所有思维模型 | 只使用可能改变结论的工具，再做覆盖检查 |
| 只有分析，没有判断 | 明确当前倾向、反转条件和下一步 |
| 为了平衡而虚构反方 | 钢人化真实可成立的立场，不制造稻草人 |
| 把解释写成事实 | 显式区分事实、推断、假设和未知 |
| 输出冗长的内部推演 | 只呈现判断所需的关键理由和证据 |
