# TREATMENT · 一块白板，蒸馏出一套个人成长操作系统

- 风格：白板讲解 Whiteboard Explainer（`styles/whiteboard/STYLE.md`）
- 素材：公众号文章《我把油管大神 Dan Koe 上千份内容，蒸馏成了可调用的个人成长操作系统》+ 作者的系统信息图
- 规格：1920×1080 · 24 fps · 约 2 分钟 · 中文配音（edge-tts）+ 中文烧录字幕 + `.srt` · −14 LUFS
- 先出关键镜头故事板，等确认再继续

## 1. 三个候选结构

1. **一条时间线**：一根长横线从左骑到右——爆文 → 我的改变 → 1297 份资料 → 11 个框架 → 判断链 → 下一步。清楚，但像在念目录，"系统"的感觉出不来。
2. **一张系统图自己长出来（选它）**：白板左边是"故事"（爆文、我被改变），右边是"系统"（资料 → 框架 → 五大领域 → 判断链）。每一段讲解都在白板上占一块地方，最后镜头退到整块白板——观众第一次看到所有区域连成**一张系统地图**，正好就是作者那张信息图的手绘版。
3. **问题驱动**：开场一个巨大问号"我总是拖延？"，整支片子是系统一步步回答它。很抓人，但会把文章的个人故事和"1000+ 份资料蒸馏"这条主线挤掉。

**选 2，并把 3 的"我总是拖延"借来做判断链的现场演示。** 理由：文章的核心论点就是"不是零散观点，而是一套系统"——让分散的板书在结尾合成一张图，是只有白板能做的论证；"全板视图"正是这个风格的原生招式。

## 2. Logline 与弧线

**Logline**：一个总在收藏却很少用上的人，把 Dan Koe 散落在上千份内容里的思想，蒸馏成一套遇到问题就能调用的系统。

- **起**：2.1 亿次浏览的爆文；他把六个话题连成一套系统；"心智是操作系统"。
- **承**：这篇文章改变了"我"——断断续续的分享（虚线）变成持续的线（实线）：先成为那个人，再让行动跟上。
- **转**：爆文只是一个切面。1297 份资料铺满一大片白板，**板擦一路擦过去**——擦剩的残影里，只留下 11 个框架。（蒸馏 = 擦除）
- **合**：五大领域 → 判断链（问题 → 意图 → 1–3 个框架 → 证据 → 下一步），用"我总是拖延"走一遍；带着真问题来；镜头退到全板，一整张系统地图；推进到最后那面小旗"下一步"，圈两圈，盖笔帽。

## 3. 标杆（只学语法）

- **RSA Animate《Changing Education Paradigms》**：学一整块板就是一张论证地图、镜头在区域间游走、结尾全板拉远。不学它的手、人物、画法和音乐。
- **minutephysics**：学"一句话 = 一幅最简图形"。不学它的形象和配色。

## 4. 色彩与字

- 三支马克笔，含义全片不变：
  - **黑 `#23262c`**：事物与结构（文字、框、图标）
  - **墨绿 `#2e6b4f`**：流程/过程（箭头、漏斗、判断链）——取自作者信息图的主色
  - **橙 `#d97757`**：每个区域唯一要紧的那一个东西（2.1亿、"博主"、11、下一步）——取自信息图的橙色虚线
- 板书全部手写：汉字用 Make Me a Hanzi 笔画中线**按真实笔顺单线书写**（单线马克笔效果）；拉丁字母/数字用单线字体。
- 字幕：圆角近白标签 + 手写感字体（ZCOOL KuaiLe 子集）+ 一小截橙色马克笔短划，底部 12% 留空。

## 7. 配乐提示图

- **钟表式极简**，96 BPM，原创：马林巴固定音型 + 颤音琴和弦 + 爵士低音提琴拨弦 + 木块嘀嗒 + 钟琴点缀。
- 开场：只有木块嘀嗒 + 一个马林巴音（2.1亿落笔时）。
- 我的故事：颤音琴稀疏和弦，温和；虚线变实线时低音提琴第一次进入。
- 系统段：**每多一个流程环节加一件乐器**（资料：木块 → 检索：马林巴 → 11 框架：低音 → 五大领域：颤音琴 → 判断链：全组）。
- 转折前：**完全静默**（板擦落板前），静默后第一个声音是板擦擦过白板。
- 结尾全板拉远：全组合奏回到主音；小旗圈完后全部停，只剩**笔帽"咔"**和一声钟琴。
