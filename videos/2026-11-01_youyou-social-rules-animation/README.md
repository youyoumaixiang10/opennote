# 豆豆的公园小课堂 · 三集蜡笔绘本动画

为攸攸（2岁5个月）制作的社交规则启蒙动画，三集独立小故事，9:16 竖屏，1080×1920，24fps，中文普通话。

| 集 | 标题 | 口诀 | 陪伴的大人 |
|---|---|---|---|
| 1 | 小手不推人 | 不推人，小手停；挥挥手，一起玩！ | 熊妈妈 |
| 2 | 别人的玩具先问问 | 别人的，背背手；先问问：可以吗？ | 熊爸爸 |
| 3 | 好奇的小眼睛 | 好吃的，看一眼；想吃了，回来说！ | 熊奶奶 |

剧本、分镜与设计依据见 `explorations/2026-11-01_youyou-social-rules-animation.md`。

## 画面风格

参考 Lemo-Opuscar 风格库中的「蜡笔儿童绘本」风格说明（只借鉴风格规则，不使用其代码或素材）：
- 暖白纸张，大约十来支蜡笔，只用一种深梅色描边，不用黑色；
- 所有线条和人物按每秒 12 帧逐格"抖动"重画，镜头运动保持每秒 24 帧平滑；
- 天空只用一种水彩；第 3 集结尾的暖色晚霞是唯一一次"上色即动作"的时刻；
- 字幕是"印在书页上的字"，一笔一字写出来。

## 设计中的教育约束（在代码里落实）

- 错误行为只出现一次，约 3 秒，不慢放、不特写、没有搞笑音效；发生的瞬间音乐停止。
- 互动时刻统一用右上角的小星星加一声"叮"，然后停顿约 4 秒，只问"要做什么呢？"，不提错误选项。
- 不强迫说"对不起"：先关心对方，再一起修复（捡起来、递回去）。
- 第 3 集里别人的食物始终是别人的，"回来说"之后的回应很真实：有时有（苹果片），有时没有（回家煮玉米）。

## 构建

```sh
sh build.sh ep1    # 配音 → 时间线 → 逐帧渲染 → 配乐与混音 → 成片 out/ep1.mp4
```

需要：Node 22 + Playwright（Chromium）、ffmpeg、Python 3.12 虚拟环境（kokoro-onnx、misaki[zh]>=0.9.4、numpy、scipy、soundfile，由 `PY` 指定），以及 Kokoro v1.1-zh 模型（由 `KOKORO_DIR` 指定的目录）：
- `kokoro-v1.1-zh.onnx`、`voices-v1.1-zh.bin`：github.com/thewh1teagle/kokoro-onnx 的 release `model-files-v1.1`
- `config.json`：即本目录的 `tools/kokoro-v1.1-zh-config.json`

成片（`out/ep*.mp4`）和配音文件（`voice/`）体积较大，没有放进仓库，用 `build.sh` 可以重新生成。

配音角色：旁白 zf_085、熊妈妈 zf_022、熊爸爸 zm_064、熊奶奶 zf_046；小动物的声音（豆豆 zf_074、米米 zf_073、嘎嘎 zm_041、果果 zm_020）由成人声音升调得到，见 `tools/tts.py`。

- `episodes/ep*.mjs`：每集的分镜脚本（镜头、机位、角色关键帧、台词、音效、音乐状态）
- `engine/`：蜡笔材质、角色骨架与表情、公园场景与道具、播放器
- `tools/`：台词导出、TTS、渲染、配乐与混音
