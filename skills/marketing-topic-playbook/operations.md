## 一、热点快反 SOP

热点快反是传播人最高频的临场决策。核心是**先判断、再动手**，判断用两个矩阵：

### 1.1 上不上：相关性 × 风险矩阵

| | 风险低 | 风险高 |
|---|---|---|
| **相关性高**（热点与品牌/品类/人群直接相关） | **全力上**：官方下场，产品关联，可投资源 | **谨慎上**：只做事实澄清或轻表态，法务先过 |
| **相关性低** | **轻量上**：评论区/玩梗级参与，不发正式物料 | **不上**：再热也不碰 |

**风险高的信号**：涉及伤亡/天灾/政治/性别对立/阶层对立/未定论的罗生门事件。判断口诀：**"品牌出现在这里，会不会显得吃人血馒头或站错队？"** 有一丝犹豫就按高风险处理。

### 1.2 什么时候上：时效窗口

- **0–2 小时（黄金窗口）**：只有轻量内容来得及——评论区神回复、官方转发玩梗。此时拼的是授权机制，不是创意
- **2–24 小时（主窗口）**：正式快反物料（海报/短视频/话题）的窗口，热点还在上升期或平台期
- **24–48 小时（尾声窗口）**：只适合"深度角度"入场——盘点、观点、反向解读，蹭表层已经晚了
- **48 小时后**：放弃，硬蹭只会暴露反应迟钝

### 1.3 响应分级

| 级别 | 动作 | 适用 |
|---|---|---|
| L1 评论区级 | 官方账号评论/转发玩梗，不出物料 | 相关性低但氛围好 |
| L2 内容级 | 快反海报/短视频/借势话题 | 相关性高、风险低 |
| L3 事件级 | 借热点造自己的事件（如友商发布会当天做对比实测） | 相关性极高，且有现成弹药 |
| L4 表态级 | 官方声明/创始人发声 | 涉及品牌自身的热点，必须响应 |

### 1.4 快反的组织前提

黄金窗口内能发出来的团队，都提前做了三件事：①授权前置（L1/L2 级内容不走完整审批链）②弹药库常备（品牌视觉模板、玩梗话术库、可快速改字的物料模板）③值班机制（热点监测有人盯、周末有人拍板）。给客户做快反建议时，先确认这三个前提是否存在。

## 二、发布会/大事件日实时作战手册

大事件日不是"发一条话题"，是**波次作战**。标准波次（以晚间发布会为例）：

| 波次 | 时间 | 动作 | 话题性质 |
|---|---|---|---|
| W1 早间预告 | 9:30 | 今日发布 + 看点清单 | 商业搜索资源 |
| W2 午间加热 | 11:30–14:00 | 嘉宾/彩排剧透、外围氛围（现场布置、排队人群） | 悬念体 |
| W3 开场即时 | 发布会开始 | 金句/亮点实时切片，每 20–30 分钟一波 | 群运营节奏 |
| W4 核心引爆 | 价格/重磅公布瞬间 | **价格话题 + 情绪话题双发**，热搜资源在此刻全押 | 价格体+口语梗体 |
| W5 当晚收口 | 结束后 1 小时内 | 一图读懂、完整回顾、首批订单战报 | 战报体 |
| W6 次日续热 | T+1 全天 | 切片二次传播（最有梗的 2–3 个瞬间）、媒体定调回收、订单数据 | 递进公式启动 |

**物料前置清单**（发布会前 48 小时必须备好）：价格公布图（多价格版本都做）、金句卡模板、一图读懂框架（留空填数）、战报海报模板、危机预案 Q&A（价格不及预期/技术翻车/嘉宾失言怎么接）。

## 三、传播投放组合：引爆—扩散—沉淀三层结构

话题不是发出去就会热，标准投放结构：

1. **引爆层（定调）**：官方主阵地 + 1–3 个头部账号/权威媒体首发，负责把话题"立住"——给出标准叙事版本
2. **扩散层（放大）**：10–30 个腰部 KOL 从不同角度跟进（评测角度/生活角度/玩梗角度），制造"到处都在讨论"的感知；全员/半员工转发在这一层
3. **沉淀层（收口）**：KOC/素人真实体验铺量（种草平台为主）+ 搜索优化，承接被话题激发的主动搜索

常见错误：预算全砸引爆层，话题热了一天但搜索承接是空的——**用户被话题打动后去搜索，看到的内容决定转化**。

## 四、长线话题资产台账

品牌应像管理商标一样管理话题资产。台账四类，每季度盘点一次：

| 资产类型 | 说明 | 维护动作 |
|---|---|---|
| Campaign 主题话题 | 节日/长线活动主话题（如"回家过年"系）| 每年迭代不换根，积累搜索沉淀 |
| 高管金句 | 有态度、可反复引用的表述 | 新语境下反复续热，一句金句可用数月 |
| 名人/IP 绑定 | 一品一名人的长期关系 | 制造"真实使用痕迹"而非硬广露出 |
| 品牌梗 | 用户自发形成或官方带起来的梗 | 官方下场玩但不玩烂，留给用户二创空间 |

**判断一次传播是否"养了资产"**：三个月后这个话题还能不能被再次挂起？不能的就是纯消耗。

## 五、效果评估指标体系（三层漏斗）

复盘时按三层看，只看第一层的复盘是自欺：

| 层 | 问题 | 指标 |
|---|---|---|
| **声量层** | 有多少人看到 | 热搜位次与在榜时长、话题阅读量、讨论量、视频播放量 |
| **心智层** | 有没有真讨论、记住了什么 | 讨论/阅读比（互动率）、自然流量占比（去掉投放后的水位）、品牌词/产品词搜索指数增量、UGC 二创量、舆情正负比 |
| **生意层** | 有没有变成生意 | 官网/门店流量、留资线索量、直播间进人、电商搜索成交 |

**关键健康度指标**：①自然流量占比（低于三成说明全靠买，话题本身不行）②讨论/阅读比（看得多聊得少 = 话题没有讨论钩子）③搜索增量（心智变化最硬的证据）。

## 六、复盘归因框架

拿到效果数据后，按此框架归因（配合模式 F 使用）：

1. **热了的**：归因到三要素——是反差强、数字狠还是人物对？句式是哪个？可复制的是机制还是运气（撞上了别的热点）？
2. **凉了的**：对照 playbook 第十节反面清单逐条排查 → 再查时机（时段/热点窗口）→ 再查投放结构（是不是只有引爆层）
3. **提炼规则**：每次复盘至少产出 1 条"下次要/下次不要"，合并进本 skill 的对应文件——**这个 skill 的价值随复盘次数增长**

复盘输出模板：

```
【话题】#……#
【结果】声量层/心智层/生意层 各一行数据
【归因】要素诊断 + 句式 + 时机 + 投放结构
【结论】下次要：…… / 下次不要：……
【更新】写入 playbook/cases 的具体条目
```

## 七、话题翻车预判（Pre-mortem 五问)

重大话题上线前，强制过一遍"假设它翻车了，是因为什么"：

1. **反噬面**：这个话题最容易被攻击的角度是什么？（价格话题→"割韭菜"；技术话题→"吹牛"；情怀话题→"卖惨营销"）
2. **对立面**：会不会激怒某个群体？（性别、地域、阶层、竞品粉丝）
3. **证据链**：话题里的每个数字和"第一"，被较真时拿得出证据吗？
4. **人物风险**：绑定的人物（名人/高管/素人）有没有历史争议？人设崩了话题怎么切割？
5. **语境风险**：上线时间点附近有没有正在发酵的负面公共事件会改变解读语境？

任何一问答不上来，就降级发布（减资源/改角度）或延后。
