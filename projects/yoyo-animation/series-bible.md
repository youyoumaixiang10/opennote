## 1. 美术方向：月夜水彩绘本 · 分层纸感

**一句话**：像一本被轻轻翻开的水彩绘本，纸张的颗粒看得见，颜色是透明的，光是纸本身的白。

### 为什么选水彩（针对 EP01，也适合整个系列）

| 考量 | 理由 |
|---|---|
| 和本集主题同构 | 水彩里最亮的地方不是涂上去的白颜料，而是**留出来的纸白**。「月亮把银色送给谁」在画面上就是「月光落在哪里，哪里就留白」。媒介本身在讲故事。 |
| 光影表现力 | 透明叠色天然适合夜色的层次：深蓝里能透出紫、透出绿，暗部不死黑。 |
| 适龄 | 边缘柔和、色彩克制，没有高饱和、硬边和强对比带来的刺激感。 |
| 可动画化 | 按「纸层」分开绘制（远景天空 / 中景 / 前景 / 角色），可以做柔和的视差移动，保留绘本感又有空间感。 |
| 系列化 | 同一套纸张、笔触、色板能装下不同季节和场景，角色辨识度靠剪影和固定配色，而不是靠夸张造型。 |

**备选方向 B：纸艺拼贴 + 水粉**（剪纸分层、水粉平涂、纸边阴影）。分层动画更方便，触感强，但「光」的细腻程度不如水彩。阶段 1 会出两版同一画面的风格测试，由家长定稿。

### 质感关键词（锁定后不改）

- 冷压水彩纸肌理，纸纹全程可见（后期统一叠加同一张纸纹，保证跨镜头一致）
- 透明水彩：天空湿画法晕染；草地、树皮用干笔
- 少量彩色铅笔线条，只用于勾勒角色轮廓和叶脉、草叶这类细节，线条轻、断续、不描黑边
- 留白 = 月光
- 构图疏朗，每个画面只留一个视觉焦点
- **不要**：高饱和糖果色、大眼萌系、3D 渲染感、塑料光泽、霓虹发光、镜头光晕、密集粒子特效、描黑粗边、扁平矢量感

## 2. 色板（锁定）

夜景不是「黑」，而是「有颜色的深」。整体明度控制在中低调，**保证 2 岁孩子在普通屏幕亮度下看得清**，不做大片死黑。

| 名称 | 色值 | 用途 |
|---|---|---|
| 夜空靛蓝 | `#233457` | 天空主体、远景 |
| 暮色蓝 | `#3E5580` | 天空靠近地平线、过渡 |
| 雾紫 | `#6E6D94` | 远处树丛、空气透视 |
| 夜草青绿 | `#34504B` | 草地暗部 |
| 月下草绿 | `#5F7E72` | 草地受光部 |
| 树影墨绿 | `#1E3433` | 树冠暗部（全片最深色，面积要小） |
| 池水深蓝 | `#1A2B45` | 水面 |
| **月光银** | `#F2F4F1` | **只留给「月亮的礼物」**：水面光点、叶缘、石头亮面、月亮本身 |
| 冷银灰 | `#C3CED3` | 月光的次亮层、月晕 |
| 攸攸姜黄 | `#D3A04A` | 攸攸的衣服与发绳 |
| 豆沙红 | `#B66A5C` | 小白兔的围巾、攸攸的小鞋（两人的视觉纽带） |
| 兔毛暖白 | `#E4DACA` | 小白兔受光面 |
| 兔毛阴影 | `#9C9AAE` | 小白兔阴影面（偏灰紫） |
| 肤色 | `#E9C4A4` / 夜间 `#C9A99A` | 攸攸皮肤 |
| 窗灯琥珀 | `#E9B86A` | 仅片头房子窗口，熄灯后不再出现暖色光源 |

### 明度层级规则（本系列最重要的视觉规则之一）

1. **「礼物」永远是画面里最亮的东西**。月光银（≈95% 明度）只出现在本镜头要观察的对象上。孩子的眼睛会自然先去找最亮的地方，所以不需要箭头、圆圈或闪光提示。
2. 小白兔虽然是白兔，但受光面最高只到 ≈85% 明度，暗面偏灰紫，**绝不能比观察对象更亮**。
3. 攸攸的姜黄色靠「暖 vs 冷」的色相对比跳出来，而不是靠亮度；明度控制在 ≈60–65%。
4. 角色和观察对象不重叠在同一个明度区间。

## 3. 角色设定

### 3.1 攸攸（Yoyo）—— 原创绘本形象（锁定项待确认）

没有使用真实照片，**不还原真实攸攸的长相**，这是一个原创的、有她气质的绘本角色。

| 项目 | 设定 |
|---|---|
| 年龄感 | 约 2 岁。3.5 头身，圆脸，短手短腿，肚子微圆，站姿略外八、重心在前，走路有一点点摇晃 |
| 剪影标志 | **头顶一个小揪揪**，用姜黄色小发绳扎起；齐耳短发，深棕近黑。系列中发型可变化，小揪揪尽量保留 |
| 眼睛 | 小而亮的深棕色圆眼，一个小高光。**不是大眼萌系**，眼睛约占脸宽 1/6 |
| 眉毛 | 淡、短、略粗的小眉毛——表情主要靠眉毛和嘴 |
| 鼻嘴 | 鼻子一个小弧；嘴小。惊喜时张成小圆「o」 |
| 脸颊 | 淡淡的水彩腮红晕染，不画圆形贴纸式红晕 |
| EP01 服装 | 姜黄色棉质长袖上衣，袖口收紧，带奶白色小圆翻领；姜黄色收口灯笼裤；奶白色短袜；**豆沙红色搭扣小鞋**（以 T3 设定图为准） |
| 性格表现 | 好奇时身体先往前探；高兴时会踮脚、拍手；说话时手会跟着比划；会用手指去「描」东西 |
| 禁止 | 大眼睛浓睫毛、化妆感、瘦长身材、成熟体态、照片写实风、过于精致的公主装扮 |

### 3.2 小白兔 —— 温柔的同伴

| 项目 | 设定 |
|---|---|
| 体型 | 圆润的梨形身体。坐着时头顶约到攸攸肩膀；后腿站起时耳尖与攸攸头顶齐平 |
| 毛色 | 暖奶白，阴影偏灰紫；耳朵内侧淡粉灰；尾巴一团圆 |
| 剪影标志 | **兔子自己的右耳，耳尖柔软地向前折下一小段**；左耳直立。（素材镜像翻转时注意：折耳必须始终是兔子自己的右耳） |
| 配饰 | **豆沙红色针织小围巾**，一端垂在胸前。除围巾外不穿衣服 |
| 脸 | 小黑圆眼，温和；小三角粉鼻；嘴部动作极小，说话时以耳朵和头部动作为主 |
| 拟人程度 | 半拟人：可以后腿站立、用前爪牵手、指东西，但身体结构保持兔子 |
| 性格 | 比攸攸「大一点点」的玩伴。会发现、会提问、会停下来等，**不讲道理、不考问、不夸张表扬** |
| 禁止 | 卡通化大头、巨大眼睛、刺眼纯白、夸张表情、和攸攸一样高大 |

### 3.3 角色在画面中的规则

- 两人同框时，攸攸在左、小白兔在右为默认站位（全片保持，避免孩子困惑「谁是谁」）
- 角色只在「人物镜头」里占画面主体；在「观察镜头」里角色退出画面或只露出一部分，把画面完全让给观察对象
- 口型：采用绘本式「弱口型」——说话时只做嘴的开合两态与头部轻微点动，不做精细对口型

## 4. 一致性控制规范

### 4.1 出图一致性（ChatGPT 生图阶段）

1. **同一集所有图在同一个 ChatGPT 对话里生成**，对话开头先粘贴【风格锁定】段落（见 EP01 出图任务包）。
2. 每次生成角色时，**附上已定稿的角色设定图**作为参考图。
3. **背景与角色分开出图**：背景图不含角色；角色单独出透明背景 PNG。这样可以在合成时统一光线、比例和位置，也避免同一角色在不同图里长得不一样。
4. 每张图都写明：光源方向（月亮在左上）、明度规则（礼物最亮）、比例与安全区。
5. 生成后按 §4.3 的清单检查，不合格的单张重出，不整批重来。

### 4.2 合成一致性（Claude 后期阶段）

- 全片统一叠加同一张水彩纸纹理和同一层轻微颗粒
- 每个镜头做一次色彩匹配，向本文件色板靠拢（统一调色曲线）
- 角色在不同背景中统一加一层「月光环境色」（左上冷光、右下灰紫阴影），让分开出的图像在同一个夜里
- 关键光效（水面光点、叶缘亮线、石头明暗）由 Claude 用程序生成或二次绘制，保证符合自然光照逻辑、可控、不闪烁

### 4.3 单图验收清单

- [ ] 风格：纸纹可见、透明水彩感、无 3D/矢量/塑料感
- [ ] 月亮/光源在左上方（或画外左上），阴影朝右下/右后
- [ ] 观察对象是画面最亮处，其他地方没有抢亮的元素
- [ ] 攸攸：小揪揪 + 姜黄发绳 + 姜黄衣服 + 豆沙红鞋 + 小眼睛
- [ ] 小白兔：兔子自己的右耳折耳 + 豆沙红围巾 + 不比观察对象亮
- [ ] 无文字、无水印、无多余角色
- [ ] 夜色不死黑，暗部仍有颜色

## 5. 适龄视觉与声音安全规范（全系列）

- **无闪烁**：任何区域亮度变化不超过每秒 3 次；光点小、边缘柔、整体画面亮度不突变
- **慢镜头运动**：推拉摇移速度不超过每秒约 2% 画面宽度；不用快速变焦、甩镜、抖动
- **长停留**：平均每镜 8–12 秒；观察镜头 ≥ 10 秒
- **低信息量**：一个画面一个焦点；背景不放会抢注意力的小动物或动态元素（彩蛋细节必须低对比、静止或极慢）
- **温和转场**：以 1–2 秒叠化和「水彩晕染」转场为主；不使用白闪、黑闪、旋转、缩放模糊
- **声音**：无突发高音量；无答题音效、倒计时、掌声、「你真棒」式音效；整体响度约 -18 LUFS，真峰值不超过 -2 dBTP
- **无字幕**（孩子不识字，字幕只会分散注意）；另附 SRT 字幕文件供家长与内容策划参考

## 6. 系列声音风格

- **主题音色**：毛毡钢琴（felt piano）+ 钢片琴/音乐盒（celesta）+ 极轻的弦乐长音铺底
- **速度**：60–68 BPM，五声音阶为主，避免不协和
- **「礼物动机」**：三个上行的钢片琴音，在每次「月亮把银色送给了……」时轻轻出现。它不是答对音效，而是一个温柔的音乐标点，可在系列中延续为「发现动机」
- **环境声**：真实、少量、有远近层次
