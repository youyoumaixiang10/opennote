## 双向钢人

### 何时使用

当用户已有明显倾向、问题存在正反立场、建议容易受确认偏误影响，或双方可能在回答不同问题时使用。

### 方法

1. 重述双方都愿意承认的真正问题。
2. 分别给出支持与反对当前倾向的最强论证。
3. 删除依赖夸张、弱证据或误解对方的论点。
4. 找出分歧属于事实预测、价值排序、风险承受还是时间尺度。
5. 指出哪项变量最可能使理性的人改变立场。

### 停止条件

当双方的最强理由、真实分歧和反转变量已经清楚时停止。不要为了对称而增加弱论点。

### 对最终答案的贡献

给出选择依据和反转条件，而不是输出一场没有裁决的辩论。

## 七类决策透镜

按需选择，不机械套满。

| 透镜 | 使用条件 | 核心问题 | 对答案的贡献 |
|---|---|---|---|
| 第一性原理 | 当前前提、目标或选项集合可能有误 | 撇开惯例后，哪些事实和约束仍然成立？ | 修正问题定义或发现伪选项 |
| 机会成本 | 选择会排除有价值的替代方案 | 选择这个方案，真正放弃的最好选择是什么？ | 显示隐藏代价 |
| 二阶影响 | 直接结果会引发后续反应 | 这件事发生之后，还会发生什么？ | 显示延迟和连锁后果 |
| 长期复利 | 选择会重复、积累或形成路径依赖 | 如果连续做一年或三年，会变成什么状态？ | 比较长期轨迹 |
| 激励分析 | 建议、行为或信息受利益结构影响 | 谁因哪个选项获益，他们的建议因此如何偏移？ | 校准信息可信度 |
| 概率判断 | 结果具有实质不确定性 | 哪个选择提高成功概率，依据是什么？ | 比较方向、范围和置信度 |
| 逆向思考 | 存在重大失败或不可逆风险 | 什么会保证失败？哪个选项正在接近它？ | 识别止损线和禁区 |

概率判断只使用可解释的数字、数据区间或明确的定性方向。没有基准率、数据或可说明的估算方法时，不生成百分比。

## 多路径探索

### 何时使用

当问题不是简单二选一、当前选项可能构成伪二分，或用户需要策略而非观点时使用。

### 方法

1. 保留真正不同的 2–4 条路径，包括可逆试验或分阶段方案。
2. 对每条路径比较适用条件、收益、代价、可逆性和最早验证信号。
3. 淘汰明显不满足硬约束的路径。
4. 推荐一条最符合当前目标与约束的路径，并说明何时切换。

不要通过给同一方案更换名称来制造“多个选择”。

当现有信息只提供“价格低”“名气大”等无法证明长期结果的代理信号时，不要借其中一项强行选边。把“现在选谁”改造成同任务、同期限、同验收标准的对称验证。用户催促直接回答不代表现实中只能先试一个；只有用户明确说明无法并行验证及其真实约束时，才依据可逆性、试验成本和信息价值选择试验顺序，并明确这不是长期合作结论。

## 决策工具收束

完成主要分析后，检查未使用的透镜是否会改变首选方案、风险等级或反转条件。若不会，停止；若会，只补充相关部分。

最终必须说明：当前首选、核心理由、主要代价、脆弱假设和一个下一步。

## 示例：异地升职

问题：薪资上涨 35%，但未来两年每周三天异地，用户倾向接受。

1. 固定底座发现：职业增量、外派条款、家庭照护和健康承受力尚未确定。
2. 双向钢人比较“职业跃迁”与“两年生活代价”，而不是把问题简化为涨薪对辛苦。
3. 机会成本检查接受后失去的家庭时间和其他求职可能；二阶影响检查健康、关系和未来议价权；逆向思考检查模糊的“两年期限”和不可控差旅。
4. 如果家庭或健康约束足以反转结论，先只问这一项；否则给条件化判断并要求把期限和差旅条件书面化。
5. 覆盖检查没有发现激励或长期复利会进一步改变结论时，不再机械补齐透镜。
