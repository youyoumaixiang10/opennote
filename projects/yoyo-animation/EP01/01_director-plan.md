## 一、导演阐述

这一集不是在教「银色」，而是在**练习看**。

我把整部片子当成一次慢慢的夜间散步来拍：镜头跟着攸攸走，走到哪里，月光就在哪里等着她。每一处「礼物」出现时，画面会安静下来，把最亮的那一点留给孩子自己去发现。

三条贯穿全片的导演原则：

1. **光就是指引。** 不用箭头、圆圈、闪烁提示。每个观察镜头里，「月亮的礼物」永远是画面中最亮的地方（见[系列视觉圣经 §2](../series-bible.md)），孩子的眼睛会自己找过去。
2. **先看，再说。** 每个观察镜头里，画面先出现 3–4 秒，旁白才开口。让孩子在被告知之前，有机会自己先看到。
3. **一个画面，一件事。** 观察镜头里角色退场或只露一角，把画面全部让给水、叶子、石头。

## 二、三种「银色」的视觉策略

| | ① 池塘：会动的银色 | ② 树叶：细细的银色 | ③ 石头：一半的银色 |
|---|---|---|---|
| 孩子要感受的 | 光会跟着水面变 | 光让轮廓变清楚 | 亮和暗同时存在 |
| 自然光照逻辑 | 月亮在前上方，水面倒影形成竖向「光路」；涟漪把一个圆圆的倒影打碎成很多跳动的光点，水静下来，光点又聚回一个圆 | 镜头在树下**朝月亮方向**仰望，叶子逆光：叶面是暗的，只有边缘透出细亮线（轮廓光） | 月光从左上方照来：左半边亮、右半边暗，明暗交界线柔和；石头的影子向右后方拖出 |
| 画面设计 | 深蓝水面占画面 70%，只有光点是亮的；两片睡莲叶在画面边缘作为静止参照物，让孩子能感觉到「光在动、叶子没动」 | 只取 3–5 片大而简单的叶子，叶形清楚（椭圆叶），背景是干净的深蓝天空和柔和月晕 | 一块圆润的灰石头放在画面中央偏左，草地极简；左右明暗面积约 1:1，交界线正好在中间 |
| 动态设计 | 一片小叶子落入水中 → 涟漪一圈圈散开 → 倒影碎成光点跳动（慢、柔，单点闪动 < 3 次/秒）→ 水面平静，光点聚回圆月 | 微风让叶子轻轻摇摆，叶缘亮线随角度变化而时粗时细、时亮时暗（真实的逆光现象） | 一片薄云慢慢飘过月亮：石头整体变暗 → 云飘走，亮面重新亮起，暗面始终是暗的。用「变化」来强调「对比」 |
| 生活延伸 | 一盆水 + 手电筒，吹一口气 | 把树叶举到灯前 | 用手电筒从侧面照一个橘子 |

> 光效全部由我（Claude）在后期用程序生成或二次绘制，而不是依赖生图模型「碰运气」画出来。这样光的方向、运动速度和亮度都可控、可调，并且符合自然逻辑、没有闪烁风险。

## 三、全局光照与空间设定

- **月亮的位置在全片保持一致：画面左上方（或画外左上）。** 光从左上前方来，阴影朝右下、右后方。
- 花园布局（全景 BG01 建立，之后所有镜头都在这个空间里）：

```
                    🌕（左上空中）
   远处树丛（雾紫）
        小池塘（左中）      大树（右中）
                 圆石头（中间草地）
  小石板路 ────────────────╮
 房子一角+窗（左下前景）   草坡（右下前景，两人坐着看月亮的地方）
```

- 全景出现三次（开场、前往池塘、第五幕回想），孩子会逐渐认出「这是我们走过的花园」，第五幕回想时能在一个画面里同时看到三处银色。

## 七、动画实现方案

### 7.1 总体技术路线

**分层绘本动画（2.5D 纸层视差）+ 程序化光效**，在 HyperFrames（HTML/Canvas + GSAP 时间轴）中搭建，渲染输出 1080p MP4。

为什么不以「图生视频」（Sora / 可灵 / Runway 等）为主：

| | 分层绘本动画（主方案） | AI 图生视频（备选，仅局部） |
|---|---|---|
| 角色一致性 | 完全一致（同一张定稿图） | 容易变形、脸会漂移 |
| 光照正确性 | 光效由程序控制，方向/速度/亮度可调 | 光常被画错，水面光点容易乱闪 |
| 闪烁风险 | 可控在安全阈值内 | 常见纹理闪烁 |
| 绘本质感 | 纸纹、笔触保持静止稳定 | 纸纹会「蠕动」 |
| 局限 | 角色动作有限（姿势切换 + 呼吸/眨眼/耳朵/轻微点头） | 动作更流畅 |

结论：全片以分层动画为主。如果家长希望 S05 / S11 走路镜头更生动，可以把这两个镜头用图生视频单独做（我会提供提示词），因为是远景小人物，变形风险最低。

### 7.2 每类元素的动法

| 元素 | 实现 |
|---|---|
| 镜头运动 | 对背景图做极慢的推、移、摇（Ken Burns + 前中远景分层视差，视差位移 ≤ 1.5%） |
| 角色 | 透明 PNG 剪纸式。呼吸（身体 0.5% 缩放循环）、眨眼（3–5 秒一次，换闭眼图）、说话（开口/闭口两态 + 头部轻微点动）、兔耳轻抖、姿势切换用 0.4 秒柔和叠化 |
| 水面光点 | 程序生成：在倒影区域用噪声场驱动的涟漪计算镜面高光点；落叶处产生同心涟漪向外扩散；光点柔边、大小 2–6px、单点闪动频率 < 3Hz；随时间衰减聚回圆形倒影 |
| 叶缘亮线 | 叶子剪纸图层 + 由叶子轮廓计算出的「朝向月亮一侧」边缘光蒙版；叶子绕叶柄小角度摆动（±3°，周期 4–6 秒），边缘光强度随角度变化 |
| 石头明暗 | 石头亮面/暗面分层；云影是一张柔边的大面积半透明图层慢慢滑过，只调暗受光层，暗面保持不变 |
| 月亮、星星 | 月晕轻微呼吸（亮度变化 < 5%，周期 8 秒）；星星极少（≤ 6 颗），慢速明暗 |
| 纸纹与颗粒 | 全片统一一张纸纹贴图（正片叠底）+ 静态颗粒，保证跨镜头质感统一 |

### 7.3 剪辑与转场

- 幕内：1–1.5 秒叠化，或在同一张图里用镜头运动「走」到下一个画面
- 幕间（S05→S06、S15→S16）：2 秒「水彩晕染」转场——深蓝色像颜料在纸上晕开，再晕出下一幕
- S22 结尾：画面融回纸色，不黑场硬切
- 禁用：白闪、黑闪、旋转、推拉模糊、快切

|---|---|---|
| 旁白 | 温暖、平稳、气声少一点，语速约每秒 3 个字，句间留白 | **首选：爸爸或妈妈本人录制。** 熟悉的声音对 2 岁孩子最有安全感，也能直接复用到纯音频故事和睡前讲述 |
| 小白兔 | 温柔、清亮，像大一点点的姐姐/哥哥，不尖、不嗲 | 另一位家长 / 家人录制，或高质量中文 TTS |
| 攸攸 | 自然的幼儿语气，句子短、带一点点奶声，**不刻意尖细** | 成人轻声演绎，或高质量中文童声 TTS。**不建议用攸攸本人声音做 AI 克隆**（隐私与长期使用的考虑） |

我可以先用本地 TTS（Kokoro 中文音色）生成一版**临时参考音轨**，用于卡节奏、做动态分镜（animatic）。临时音轨的中文自然度有限，不建议作为成片配音。家长录音的方法见 [02_script.md 附录](02_script.md#附录家长录音指南)，录好后我负责降噪、统一音量、对位。

### 8.2 音乐

- **编制**：毛毡钢琴 + 钢片琴（或音乐盒）+ 极轻的弦乐长音
- **速度/调性**：64 BPM，D 大调五声为主，温柔、透明、有留白
- **结构**：A 主题（片头/第一幕）→ 轻快一点的「散步」变奏（走路段）→ 观察镜头时音乐退到几个单音 → 第五幕主题完整再现 → 结尾单个长音和弦渐弱
- **礼物动机**：三个上行钢片琴音（A–D–F♯），在三次「月亮把银色送给了……」后出现，第五幕回想时再出现一次
- **来源方案**（我无法在本环境内创作高品质音乐，以下三选一）：
  1. **AI 音乐生成**（如 Suno 等）——我提供的提示词：`gentle lullaby, felt piano and celesta, soft string pad, 64 bpm, D major pentatonic, sparse, calm, moonlit night, children's picture book film score, no drums, no vocals, instrumental, 4 minutes`（注意确认平台授权条款）
  2. **免版税曲库**（Pixabay Music / Free Music Archive 等，选 CC0 或可商用授权），检索词：`felt piano lullaby`、`music box night`、`celesta sleepy`
  3. 家人或朋友用钢琴/音乐盒录一段简单旋律——这是最有温度的方案
- 拿到音乐后，由我负责剪辑对位、在对白处自动避让（ducking，音乐降 8–10dB）

### 8.4 混音层次

旁白/对白在最前（-18 LUFS 附近）→ 音乐在中层，有对白时自动避让 → 环境声在最后、最宽。整体 -18 LUFS，真峰值 ≤ -2 dBTP。

## 九、质量自检（对照家长提出的六个标准）

| 标准 | 本集设计中的回应 |
|---|---|
| 看得懂吗？ | 一条散步路线、三站、重复句式「月亮把银色送给了……」；台词短；不出现抽象概念 |
| 看得清吗？ | 观察对象永远是画面最亮处；观察镜头里角色退场；每个观察镜头 ≥ 10 秒 |
| 画面真的美吗？ | 水彩留白 = 月光；克制的夜色色板；每个画面一个焦点；纸纹质感 |
| 激发主动观察？ | 观察镜头「先看 3–4 秒再说」；两处真正的停顿；攸攸用手指「描」叶缘，可模仿 |
| 能延伸到生活吗？ | 三个现象都能用一盆水、一片叶子、一个橘子 + 手电筒在家重现 |
| 适合反复体验？ | 第二遍可能发现：倒影聚回圆月、叶缘亮线忽粗忽细、云飘过时石头变暗、结尾藏着的小青蛙和露珠；S02 与 S20 首尾呼应 |
