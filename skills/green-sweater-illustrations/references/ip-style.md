# 绿毛衣女孩 IP

## 角色定义

绿毛衣女孩是这个 Skill 的固定视觉 IP。

默认每张图都要出现她。她不是吉祥物、贴纸或纯头像，而是正在认真参与系统运转的荒诞工作者。她要承担画面的核心动作，让文章里的判断、流程、结构或状态被看见。

## 外形

- 年轻女性，黑色中长发，自然蓬松，有松散发丝和轻微层次。
- 温和清爽的五官，大眼睛，细眉，表情自然，不夸张。
- 标志性服装是深绿色宽松高领毛衣，领口厚，袖子偏长，有针织纹理。
- 下装是黑色宽松长裤，鞋子是白色休闲鞋。
- 体态放松，略带生活感；可以正面、侧面、半身或全身出现。
- 整体保持手绘线稿感，不要变成写实肖像、商业二次元海报或精修角色立绘。

## 性格

- 温和、聪明、认真，但做的事可以有点荒诞。
- 像一个低调的系统操作员、内容整理者或观察者。
- 有轻微冷幽默，不卖萌，不夸张表演。
- 可以微笑、思考、惊讶、专注、困惑，但表情要克制。
- 像在白板草图里真的负责某个工作。

## 常见职责

让绿毛衣女孩承担核心动作：

- 搬运、分拣或整理素材。
- 拉线汇聚信息源。
- 卡在断点里，或把断点重新接上。
- 在机器里操作“判断”杆。
- 拿放大镜、夹板、便签或笔观察问题。
- 把复杂内容折叠、压缩、拆开或装箱。
- 牵着承接路径，打开下一扇门。
- 举警告牌看坑，但不要像表情包。
- 在旁边搭桥、开门、称重、记录、修补、分层。
- 用轻微荒诞的动作解释一个抽象概念。

## 禁止

- 不要画成黑色怪物、圆点眼小生物。
- 不要画成过度可爱的吉祥物、表情包或儿童卡通角色。
- 不要改掉标志性深绿色高领毛衣。
- 不要给她换成复杂服装、华丽裙装、制服、科幻装或明显品牌服饰。
- 不要画成商业二次元海报、精致立绘、偶像写真或真实照片。
- 不要让她只是站在角落里看。
- 不要让人物抢走结构表达；她要服务于正文隐喻。

## 判断标准

如果去掉绿毛衣女孩，图的核心隐喻还能完全成立，说明角色太装饰了；要重写提示词，让她成为动作主体。

如果保留动作但看不出黑色中长发、深绿色宽松高领毛衣、黑色宽松长裤或白色休闲鞋，说明角色识别度不够；要补充外观约束。
