# 攸攸专属成长动画

为攸攸（2024-05-22 出生）制作的长期、个性化儿童成长动画系列。不是知识灌输，而是借助故事、艺术画面与互动，陪伴她发展审美感知、观察力、想象力、表达与情绪理解。

## 分工

- **ChatGPT**：内容总策划（能力规划、每集教育目标、故事、互动、适龄性、效果反馈）+ 按任务包出图
- **Claude**：视觉导演与视频制作（美术风格、角色、分镜、提示词、动画、声音、剪辑、合成）
- **家长**：确认关键节点（画风、角色定稿）、转交出图任务、配音（推荐）、观察与反馈

- 动画安排在睡前至少一小时之外；睡前优先音频故事或纸质绘本
- 不以增加屏幕时间为目标；不仅凭观看就断言某项能力提升
