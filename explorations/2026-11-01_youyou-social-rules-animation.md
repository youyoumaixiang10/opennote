# 攸攸的社交规则启蒙动画：行为分析 · 设计评估 · 三集剧本分镜 · 亲子练习

**Date**: 2026-11-01
**Source**: notes from 2026-11-01 to 2026-11-01（`notes/2026-11-01_youyou-social-rules-animation-request.md`）
**Lens**: 儿童发展心理学（2—3岁）+ 行为干预 + 幼儿动画制作

---

## 写在前面：三个最重要的结论

1. **攸攸"知道规则"，但还"管不住手"，也还没真正把规则和"别人会疼、会难过"连起来。** 她会趁大人不注意才推，说明她已经知道"大人不让"——再多讲"不可以"不会有新的效果。现在缺的是三样东西：**一个能替代的动作**、**一个看得见的理由（别人的感受）**、**大人在现场及时拦一下**。
2. **视频只是辅助，不能单靠它。** 3岁以下的孩子从屏幕上学到的东西，很难自己用到现实里（"视频缺陷效应"）。真正起作用的是：大人陪着看、在家演一演、到了公园用**同一句口诀、同一个动作**提醒她。动画的作用是给全家人和攸攸一套共同的"台词"和"动作"。
3. **原设计方向是对的，但有三个地方要改，不然可能反过来教会她错误动作**：错误行为只出现一次、时间短、一点也不好玩；互动提问只问"该怎么做"，不问"推还是不推"；第3集结尾不能让"盯着看"换来别人的食物。

## 第一部分：行为背后可能的心理机制

### 1.1 先看 2岁5个月这个年龄

| 发展领域 | 这个年龄的典型状态 | 对攸攸意味着什么 |
|---|---|---|
| **语言 vs. 自控** | 语言理解可以很超前，但冲动控制（研究中叫"抑制控制""努力控制"）一般到 3—5 岁才明显提升 | 她说得好、听得懂，大人容易高估她"管住自己"的能力。**"知道"和"做到"之间差得很远是正常的** |
| **身体攻击** | 纵向研究（如 Tremblay 等人的追踪研究）显示，推、打、抢这类身体攻击大约在 2—3 岁出现得最频繁，此后多数孩子随着语言和自控力发展而减少 | 推人在这个年龄**常见，但不能放任**——减少的前提是大人持续、一致地教她"用什么代替推" |
| **共情** | 1—2 岁就能对亲近的人的难过表现出关心（Zahn-Waxler 等人的研究） | 她会安慰妈妈，说明共情的"种子"已经有了。但**把共情延伸到陌生的小宝宝，并且在冲动的那一刻想到"我推了他会疼"**，还需要大人一次次帮她连起来 |
| **理解他人想法** | 1 岁半左右开始知道"别人想要的东西和我不一样"；完整理解"别人怎么想"（心理理论）要到 4 岁左右 | "别人被盯着会不舒服"这类理由，对她来说还偏抽象，需要配上**能看见的画面**（对方把饼干抱紧、不吃了） |
| **所有权** | 2 岁时"我的！"很清楚；"那是别人的，别人有权决定"大约在 3 岁才比较稳（Rossano、Rakoczy 和 Tomasello 2011 年的研究：3 岁孩子会替别人抗议"你拿了他的东西"，2 岁孩子更多只关心自己的东西） | 现在正好是建立"别人的东西"概念的窗口期，但要预期会反复 |
| **因果探索** | 幼儿喜欢反复做实验："我这样做，会发生什么？"——扔东西、推倒东西都属于这一类 | 推人、拍掉东西，有一部分可能是"社交版的因果实验"：推一下，对方会怎样、大人会怎样 |
| **规则的来源** | 这个年龄的规则大多来自外部："大人不让""会被说"。从"怕大人说"到"我不想让别人疼"，需要长期积累 | 这正是你们说的最终目标：**理解别人，而不是害怕批评**。研究上，最能帮孩子把规则变成自己的规则的，是"温暖的关系 + 指出行为对别人的影响"（Hoffman 称之为"诱导式管教"，Kochanska 的研究也支持这一点），而不是单纯的禁止和惩罚 |

### 1.2 行为1：盯着别人吃东西

**已观察到的事实**
- 在公园，看到小朋友或大人吃东西，会站到对方旁边一直盯着看。
- 反复出现。
- 家长说"不可以这样""这样不礼貌"，效果不明显。
- （需求中**没有**提到她伸手拿过别人的食物。）

**可能的解释（都是假设，可以同时存在）**

| 假设 | 支持它的线索 / 怎么验证 |
|---|---|
| **对食物和"别人在干什么"好奇**：吃东西的场景对幼儿非常有吸引力 | 观察她是不是对所有吃东西的人都这样，还是只对某些零食 |
| **期待被分享，而且可能被"偶尔奖励"过**：公园里常有大人看到小孩盯着看，就递一块过来。只要偶尔成功过几次，这个行为就会非常顽固（行为学上叫"间歇强化"，比每次都成功更难消退） | 回想：她盯着看之后，有没有被别人给过吃的？家里人有没有因此去买？ |
| **饿了 / 渴了** | 记录发生时间：是不是多在饭点前、玩了很久之后 |
| **还不懂"社交距离"**：她不知道站很近、一直看会让别人不舒服 | 符合年龄特点 |

**为什么"不可以这样""不礼貌"没用**
- "不礼貌"太抽象，2 岁半的孩子还理解不了；"这样"指的是哪样，她也不清楚——是"看"不行？还是"站"不行？
- 只说了**不能做什么**，没告诉她**该做什么**。她的愿望（想吃、好奇）还在，却没有别的出口。
- 往往是事后说的，而且可能伴随着大人的注意力，本身也可能变成一种"回报"。

**需要特别注意**：这三种行为里，"盯着看"的伤害最小，本质上是好奇加上愿望。目标可以定得温和一些：**看一眼可以，站着一直看不行；想吃了，回来告诉家人**。不要把它和推人放在同样的严重级别上。

### 1.3 行为2：推比自己小的小朋友

**已观察到的事实**
- 有时突然推公园里的小弟弟、小妹妹。
- 更常挑比自己小的孩子，面对大孩子一般不这样。
- 有时趁大人不注意才推。
- 第一次没推成功，有时会再试一次。

**从事实能推出什么、推不出什么**

| 事实 | 可以合理推出 | **不能**推出 |
|---|---|---|
| 趁大人不注意 | 她**已经知道**大人不允许推人；规则目前还是"外部的"（怕大人）而不是"内部的"（不想让别人疼） | 不能推出"她很狡猾""有心机"。这其实是规则意识正在形成的表现 |
| 挑小的 | 她会根据对方的反应来选择：小宝宝不会推回来，反应也更"明显"（会倒、会哭） | 不能推出"欺负弱小"。成人意义上的"欺凌"需要理解伤害、有意持续针对某人，2 岁半的孩子一般还达不到这种认知水平 |
| 没成功会再试 | 这个动作有明确目标，她想看到某个结果 | 那个"结果"是什么还不知道：对方倒下？哭？大人的反应？还是想要对方的位置？ |

**可能的动机（需要观察来区分，不同动机对应不同的干预重点）**

| 可能动机 | 典型表现 | 干预重点 |
|---|---|---|
| **社交兴趣，但不会用别的方式开始互动**：小宝宝对幼儿很有吸引力，"推一下"是很笨拙的"我注意到你了" | 推之前盯着小宝宝看，推完还站在旁边 | 教"挥挥手 / 一起玩吧" |
| **因果实验 / 想看对方的反应** | 推完观察对方，没反应就再推 | 让她看见真实的结果（对方疼、哭），推了以后**不给有趣的反应** |
| **想要空间或物品**（滑梯口、秋千、对方手里的东西） | 发生在排队、窄路、抢玩具的场合 | 教"请让一下"和"等一等" |
| **兴奋过度 / 累了** | 玩久了、人多吵闹时更多 | 安排休息，减少刺激 |
| **模仿**（托班、其他孩子、动画） | 突然开始出现 | 了解她在哪里见过 |
| **对"小宝宝"的复杂情绪**（例如家里或身边有新出生的婴儿、大人当着她夸小宝宝） | 尤其针对很小的婴儿 | 帮她说出感受："你是不是想让妈妈看你？" |

> 第 1.6 节有一张 **ABC 观察记录表**，建议爸爸和奶奶连续记录 1—2 周，大概就能看出哪一种动机最主要。

### 1.4 行为3：故意碰、拍、扔别人的东西

**已观察到的事实**
- 突然伸手拍一下别人的东西。
- 故意碰掉。
- 把别人的东西扔掉然后跑开。
- 看起来是主动的，不是不小心。

**可能的机制**
- **"扔"和"让东西掉下去"是幼儿最着迷的因果游戏之一。** 扔出去、掉下来、发出声音、别人有反应，每一步都很有意思。
- **"扔了就跑"很像在邀请别人来追。** 如果有人追（哪怕是生气地追），对她来说可能就是一场追逐游戏。这一点在干预时很关键：**不要笑着追，也不要大喊着追。**
- **"别人的东西"这个概念还在形成中**（见 1.1 所有权一栏）。
- **不会用语言开口**：想碰、想玩，但还不会说"我可以玩吗？"

### 1.5 三种行为的共同点

1. **都发生在公园、面对不熟悉的人**——家里的规则还没有"迁移"到外面。
2. **她都有一个合理的愿望**（好奇、想玩、想吃、想互动），**只是方式不对**。干预的核心是**保留愿望、替换方式**。
3. **大人当时的反应可能在无意中强化了行为**：大声"不可以！"、长篇说教、追着跑、给吃的，对 2 岁的孩子来说都是"有趣的结果"。
4. **"不可以"已经说够了，现在缺的是"可以"。**

### 1.6 ABC 观察记录表（建议记录 1—2 周）

| 日期时间 | A 发生前（地点、对象、她在干什么、饿/累吗、大人在哪） | B 行为（具体做了什么） | C 发生后（对方怎么样、大人怎么做、她什么反应） | 推测动机 |
|---|---|---|---|---|
| 例：10/28 16:40 | 滑梯旁，约 1 岁半的小弟弟挡在梯子口，奶奶在 3 米外看手机 | 推了小弟弟后背，没推倒，又推一次 | 小弟弟哭了，奶奶跑过来大声说"不能推！"，她笑着跑开 | 想上滑梯？想看反应？ |

记录时只写看到的事实，不写"她又欺负人了"这种判断。

## 第二部分：对原动画设计的评估

### 2.1 逐条评估

| 原设计原则 | 是否适合 2岁5个月 | 评估与调整 |
|---|---|---|
| 1 故事化 | ✅ 适合 | 每集只讲**一个**场景、**一个**核心替代动作。同一画面里的角色不超过 3 个 |
| 2 具体化 | ✅ 非常关键 | 进一步落实为**动作词**："小手停""背背手""回来说"。"身体属于他自己"这类表述对她偏抽象，换成"推了，米米会摔倒，会疼" |
| 3 正向示范 | ✅ 核心 | 正确动作的出镜次数**至少是错误动作的 3 倍**（示范 → 口诀 → 互动 → 结尾口诀） |
| 4 情绪安全 | ✅ | 另外注意：**不强迫主角说"对不起"**。被逼着说的道歉，容易变成"说完就没事了"的仪式。改成**关心对方 + 修复行动**（问"疼吗？"、捡起来、递回去） |
| 5 明确边界 | ✅ | 大人的台词统一用 **"停。我不让你推人。"**：语气平静、句子短、不讲道理、不吼。坚定体现在**动作**上（握住小手），不在音量上 |
| 6 口诀 + 动作 | ✅ 非常适合 | 每句 3 个字、四个短句、有节奏、每句配一个手势。手势本身就是**自我控制的动作**（例如"背背手"让手有地方放） |
| 7 真实后果 | ⚠️ 需要谨慎 | 见 2.2 第①条 |
| 8 互动停顿 | ⚠️ 需要调整 | 见 2.2 第③④条 |
| 时长 60—90 秒 | ✅ | 符合这个年龄的注意力长度 |
| 主角不是攸攸 | ✅ 正确，但需补一座"桥" | 主角和攸攸差太远，她可能想不到"这和我有关"。由大人在看完后搭桥："攸攸的小手也会挥挥手吗？"（不要说"你就像豆豆一样推人"） |
| 9:16、慢节奏、无闪切 | ✅ | 补充：每个镜头只做一件事，一般 4—8 秒；不用快速切换和 360° 转场 |

### 2.2 可能强化错误行为或产生负面效果的风险

| # | 风险 | 原理 | 本剧本的处理 |
|---|---|---|---|
| ① | **演示推人，反而教会了推人** | 班杜拉的"波波玩偶"实验发现：孩子看过攻击动作后就"学会"了，即使示范者受了罚，动作本身也已被记住，只是暂时不做 | 错误动作**只出现一次**、**3 秒**、不慢放、不特写、不重播；没有滑稽音效，没有任何人笑；**两次互动都不重现伸手推的姿势** |
| ② | **后果画面变得"好玩"** | 夸张跌倒、"啵嘤"音效、对方的滑稽表情，会让推人变成笑点 | 跌倒是"坐到软草地上"，配真实的轻声落地音；哭声轻、不超过 2 秒；主角的表情是**愣住和担心**（示范共情） |
| ③ | **互动提问里出现错误选项** | 问"推还是挥手？"等于又把"推"说了一遍，幼儿还可能大声喊出"推！"并觉得好玩 | 只问开放性的"小手要做什么呢？"，画面只给正确线索 |
| ④ | **停顿时长不合适** | 2 岁孩子从听到问题到反应通常需要 3—5 秒；视频不会等人 | 统一停顿 **4 秒**，并用**固定的"小星星闪 + 叮"**提示"轮到你了"。家长在旁边陪看，必要时按暂停 |
| ⑤ | **"盯着看"换来了吃的** | 如果结局是对方把食物分给主角，等于在教"盯着看就有得吃" | 第3集里食物来自**自己家人**，或者"回家再吃"；别人的食物始终是别人的 |
| ⑥ | **展示她没做过的行为** | 需求里没提到她拿过别人的食物；在动画里演"伸手拿"等于给她出了一个新主意 | 第3集不演"拿"，只用一句话交代"那是果果的饼干" |
| ⑦ | **"扔了就跑"被演成追逐游戏** | 跑开 + 被追 = 游戏 | 第2集只演"拍掉"，不演"扔了跑开" |
| ⑧ | **视频被当作惩罚** | "你又推人了，回家看视频！"会让视频带上羞耻感，她会抗拒 | 只在平静、开心的时候看；**出门去公园前看**效果最好（相当于预习） |
| ⑨ | **只靠视频** | 3 岁以下的孩子从屏幕到现实的迁移能力很弱（Anderson & Pempek 2005 等关于"视频缺陷效应"的研究） | 必须配合第五部分的线下练习；大人陪看、陪做动作 |
| ⑩ | **一集教太多** | 原第1集同时有"挥手 / 打招呼 / 一起玩 / 请让一下 / 身体边界"，第2集有"先问 / 尊重拒绝 / 捡起来 / 扔软球" | 每集一个核心动作：第1集"挥挥手"，第2集"先问问"，第3集"回来说"。"请让一下"放进线下练习，以后可以再做一集 |

### 2.3 对原设计的主要调整（汇总）

1. 三集的大人分别是**妈妈、爸爸、奶奶**——对应现实里陪她去公园的人（爸爸和奶奶是推人行为的主要观察者），让三位大人在现场说**完全一样的台词**。
2. 统一的"拦截句"：**"停。我不让你推/拍……"** + 握住小手 + 一句说明后果的话。不加长篇解释。
3. 统一的修复流程：**先关心被推、被拍的人 → 一起修复 → 再教替代动作**。不强迫道歉。
4. 统一的互动信号：**小星星 + "叮"**。
5. 表扬要具体，并且**落到对方的感受上**："你挥挥手，米米就笑了。"不用笼统的"真乖""好孩子"。这样表扬的是她做了什么、对别人有什么影响，而不是她这个人。

## 第三部分：三集口诀一览

| 集 | 口诀 | 配套动作 |
|---|---|---|
| 第1集 | **不推人，小手停；挥挥手，一起玩！** | 不推人：双手交叉抱在胸前 → 小手停：双手合拢放在肚子前 → 挥挥手：挥手 → 一起玩：张开双臂 |
| 第2集 | **别人的，背背手；先问问：可以吗？** | 别人的：手指轻轻指向前方 → 背背手：双手背到身后 → 先问问：食指点点嘴巴 → 可以吗：歪头、双手摊开 |
| 第3集 | **好吃的，看一眼；想吃了，回来说！** | 好吃的：摸摸肚子 → 看一眼：双手圈在眼前当"望远镜"再放下 → 想吃了：点点嘴巴 → 回来说：转身拍拍自己胸口（现实中就是跑回家人身边） |

口诀的共同特点：3 字一句、可以拍手打节奏、全部是**正向动作**（只有第1集保留"不推人"，因为推人涉及安全，需要明确说出底线）。第3集用"回来说"而不是"找妈妈"，不管谁带她去公园都适用。

## 第四部分：三集完整剧本与逐镜头分镜

### 统一设定

**角色**
| 角色 | 形象 | 说明 |
|---|---|---|
| **豆豆**（主角） | 圆滚滚的小熊，约 2 岁半，穿黄色背带裤 | 和攸攸年龄相仿，但不是攸攸。用"它" |
| 熊妈妈 / 熊爸爸 / 熊奶奶 | 温和的大熊，戴围巾 / 眼镜 / 小花帽 | 三集分别出场，说话慢、蹲下说话 |
| **米米**（第1集） | 比豆豆小一圈的小兔，戴小帽，走路摇摇晃晃 | 对应"比自己小的小朋友" |

## 第五部分：配套线下亲子练习

### 5.1 怎么看视频

| 要点 | 做法 |
|---|---|
| 什么时候看 | **出门去公园前**看一集，效果最好（相当于预习）；或者在平静、开心的时候看。**不要在她推人之后拿视频当惩罚** |
| 看几遍 | 每天 1—2 次，每次 1 集。一集连续看 3—5 天再换下一集。建议先看第1集（推人涉及安全，最优先） |
| 怎么陪看 | 大人坐在旁边一起看。到小星星闪的时候，大人自己先做动作或说答案，邀请她跟着做；她没反应就按暂停，等一等 |
| 看完搭桥 | "豆豆的小手会挥挥手，攸攸的小手会做什么呀？"——**只用正面方式把她和豆豆连在一起**。不要说"你也推人了，跟豆豆一样" |
| 口诀动作 | 看完后站起来，一起做一遍口诀动作，当作身体游戏 |

### 5.2 在家玩的练习游戏（每次 3—5 分钟）

**游戏1：小手魔法（对应第1集）**
大人说口诀，她做动作；然后反过来，她说、大人做。可以故意做错（比如该挥手的时候抱胸），让她来纠正大人——孩子特别喜欢当老师。

**游戏2：玩偶小剧场（三集通用）**
用两个毛绒玩具演公园：一个大的、一个小的。大人让大玩偶"想推"小玩偶，**问攸攸："快！它的小手要做什么？"** 让她去拦、去教玩偶挥挥手。
> 原理：让孩子扮演"教的人"，比反复被教更能把规则变成她自己的（她在帮别人守规则，而不是被别人管）。
> 注意：玩偶只做"想推"的样子，大人马上让攸攸介入，不真的演推倒。

**游戏3："可以吗？"游戏（对应第2集）**
家人各拿一样东西，攸攸背着手问"我可以玩吗？"，家人轮流给出三种回答：
- "可以！给你。"
- "等一下，我玩完给你。"（然后**真的**在一两分钟后给她——让她相信"等一等"是有用的）
- "这个不行，这是爸爸的手机。"（然后给她一个替代品）

反过来，也让她拿着自己的玩具，被大人问"我可以玩吗？"，**让她练习说"不行"和"等一下"，大人要尊重她的拒绝**。她自己的拒绝被尊重过，才更容易理解别人的拒绝。

**游戏4：能推的和不能推的（对应第1集）**
在家准备一个空纸箱、一辆玩具推车、一个大抱枕：
- "箱子可以推吗？"——"可以！"（让她用力推）
- "小车可以推吗？"——"可以！"
- "妈妈可以推吗？""小宝宝可以推吗？"——"不推人！"（做抱胸动作）

**同样玩"能扔的和不能扔的"**：软球扔进筐，可以；别人的东西，不扔。
> 原理：她"想推、想扔"的身体需要是真实的，**给它一个合法的出口**，比单纯禁止更有效。去公园时可以带上她自己的软球。

**游戏5：看一眼，回来说（对应第3集）**
家里有人吃水果时，大人提示："好吃的，看一眼——想吃了？"让她跑回身边说"我也想吃"，**然后马上认真回应**（给一块，或者说明"等吃饭的时候吃"）。

### 5.3 出门前 30 秒预告

在家门口蹲下，和她一起做一遍三集的口诀动作，然后说：
> "今天去公园。看到小弟弟小妹妹——小手怎么做？（挥挥手！）
> 看到别人的玩具——（背背手，先问问！）
> 看到别人吃好吃的——（看一眼，回来说！）"

### 5.4 公园现场：事前 · 事中 · 事后

**① 事前：预防最重要**
- **在小宝宝附近，大人要保持一臂距离以内。** 她会趁大人不注意才推，所以"看着她"本身就是最直接的干预。奶奶和爸爸在这段时间尽量不看手机（这不是指责，而是这个阶段确实需要）。
- **认得出前兆**：快步走向小宝宝、双手抬起、表情兴奋、盯着某个孩子。看到前兆就**提前**介入，轻轻握住她的手："小手停——要挥挥手吗？"在推之前拦住，效果远好于推了以后再教育。
- 带上她自己的零食、水和软球。
- 人很多、她很累或很兴奋的时候，主动换到人少的地方或回家。

**② 事中：推人发生了怎么办（全家统一流程）**

| 步骤 | 做什么 | 怎么说 |
|---|---|---|
| 1 停 | 平静地走过去，蹲下，握住她的双手 | "停。我不让你推人。" |
| 2 先照顾对方 | **先关心被推的孩子**，大人自己向对方家长简单道歉（这也是示范） | "小弟弟，你疼吗？""不好意思，我们在学不推人。" |
| 3 说出后果 | 一句话，指向对方的感受 | "你推了，弟弟摔倒了，在哭。" |
| 4 修复 | 带她做一个小小的修复动作：问一问、帮忙捡起掉的东西、挥手说再见。**不强迫她说"对不起"**；如果她自己愿意说，很好 | "我们问问弟弟：疼吗？" |
| 5 给替代 | 做口诀动作 | "小手停，挥挥手。" |
| 6 如果再推 | **平静地带她离开那片区域几分钟**，到旁边坐一坐，等她平静下来再回去试。这不是惩罚，而是"小手还没准备好" | "小手还没准备好，我们先到这边休息一下。等小手准备好了，再去挥挥手。" |

**避免**：大声喊"不能推！"、在众人面前长篇说教、"你怎么老欺负小朋友"、"坏孩子"、"再推就打你 / 警察来抓你"、笑着说"哎呀你这个小调皮"（任何一种强烈情绪反应都可能变成她想看到的"结果"）。

**③ 碰、拍、扔了别人的东西**
- "停。这是哥哥的。"握住手 → "掉了，捡起来。"**大人陪她一起捡、一起还**（她做主要动作，大人辅助）。
- 如果她扔了就跑：**不要笑着追，也不要大喊着追。**平静地走过去，牵住她，回来一起捡。让"扔了跑"不再变成追逐游戏。
- 然后马上给出口："想扔吗？我们扔自己的球，扔进筐里！"

**④ 盯着别人吃东西**
- 走过去蹲下，先说出她的愿望："你在看哥哥的饼干，看起来很香，你也想吃，对吗？"
- 牵她回到自己的位置："想吃了，回来告诉妈妈。"
- 认真回应：有自己的零食就给；没有就说清楚"今天没带，回家吃 / 等会儿我们去买"，并且**说到做到**。
- **全家统一一个原则**：如果别人主动给吃的，由家人决定接不接受（也关系到食品安全和过敏），接受时教她说"谢谢"。但大人**不要**因为她盯着看就去买，否则等于在奖励盯着看。

**⑤ 抓住她做对的瞬间（这一条最重要）**

她每次做对，哪怕只是**没有推**，都要马上、具体地说出来，并且说到**别人的感受**上：
- "你刚才对小妹妹挥手了，小妹妹笑了！"
- "你先问了'可以吗'，姐姐就给你玩了。"
- "你看了一眼就回来告诉妈妈，妈妈好喜欢你来告诉我。"
- "你走过小弟弟身边，小手停得好好的。"

表扬的比例目标：**做对时得到的关注，要明显多于做错时**。现在很可能反过来：她推人时大人反应最强烈，她乖乖玩时没人注意。

### 5.5 全家统一话术卡（建议打印贴在门口）

| 场景 | 不说 | 统一说 |
|---|---|---|
| 推人前兆 | "你又想干嘛！" | "小手停——挥挥手？" |
| 推了人 | "不可以！不礼貌！你怎么又欺负人！" | "停。我不让你推人。你推了，弟弟摔倒了，在哭。" |
| 拍、扔别人的东西 | "手欠！""你怎么这么讨厌" | "停。这是哥哥的。掉了，捡起来。" |
| 想玩别人的玩具 | "那是人家的，不许碰！" | "背背手，先问问：可以吗？" |
| 被拒绝了 | "人家不给就算了，有什么好哭的" | "你很想玩，有点着急。他说等一下，我们等一等。" |
| 盯着别人吃 | "别看了！丢人！" | "看起来很香，你也想吃，对吗？想吃了，回来说。" |
| 做对了 | "真乖""好孩子" | 具体描述 + 对方的感受："你挥挥手，妹妹笑了。" |

### 5.6 进阶：攸攸版"成功小视频"

当她在公园里做对的时候（对小宝宝挥手、背着手问"可以吗"），**用手机录下来**。回家和她一起看："看！攸攸挥挥手，小妹妹笑了！"
> 这种方法叫"视频自我示范"：让孩子反复看到**自己做对的样子**。它和动画里"主角不是攸攸"不矛盾——动画里的错误由豆豆来犯，攸攸只出现在成功的画面里。这样能帮她形成"我是会挥挥手、会先问问的小朋友"这样的自我认识。

### 5.7 合理预期与何时求助

- **会反复，这是正常的。** 一般需要几周到几个月的持续、一致干预，才会看到稳定的变化。好几天没推，突然又推一次，不代表失败。
- **衡量进步看三个指标**：①推人的次数（用 ABC 表记录）；②被大人拦下后，她能多快停下来；③她**主动**做出替代行为的次数（挥手、问"可以吗"、回来说）。
- **建议咨询儿童保健科或发育行为儿科的情况**：家庭一致干预 6—8 周以后推人的频率没有下降，或者越来越多；出现造成伤害的攻击（咬、抓伤、打头）；在家里也频繁攻击家人；或者同时伴有语言、睡眠、情绪方面的明显变化。
- 也可以留意：她最近有没有在托班或别的地方**被推过**、看过有推人情节的动画、身边有没有新出生的小宝宝。这些都可能是诱因。
