# EP01 家长反馈模板

> 观看或活动后 1–3 天内填写即可，不需要每一项都填。填好后发给 ChatGPT（内容策划）和 Claude（视觉制作），用于调整下一集。
> 记录观察到的事实就好，不需要评价孩子「学会了没有」。

---

**基本信息**
- 日期：
- 形式：□ 视频　□ 音频故事　□ 家长朗读　□ 亲子活动（版本 ___）
- 第几次接触这一集：
- 时间与状态（如：下午 4 点，刚睡醒，心情好）：
- 一起观看/参与的人：

**1. 注意力**
- 全程看完了吗？□ 是　□ 中途离开（大约在 ______ 的时候）
- 她看得最专注的画面是：
- 她明显失去兴趣的画面是：

**2. 两个互动点的反应**（照实记录，没有反应也是正常的）

| 互动 | 她的反应（原话 / 动作 / 安静看） |
|---|---|
| 「树叶上的银色在哪里？」 | |
| 「月亮还会把银色送给谁？」 | |

**3. 她自己说的话**（请尽量记原话，最有价值的一项）
- 观看时：
- 观看后 / 生活中：

**4. 生活中的延伸**
- 之后几天，她有没有在生活中主动指出亮光、影子、水里的光？在哪里？说了什么？

**5. 感受与不适**
- 她的整体情绪：□ 平静　□ 开心　□ 兴奋　□ 无聊　□ 害怕/紧张
- 有没有觉得太暗、太慢、太长、听不清的地方？
- 有没有让她不舒服或害怕的画面、声音？

**6. 重复意愿**
- 她有没有要求再看/再听？□ 有（主动提了 ___ 次）　□ 没有
- 她是怎么称呼这一集的？（如「月亮那个」「小兔子」）
