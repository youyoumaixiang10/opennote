# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是干净白底。
- 有绿毛衣女孩。
- 角色能看出参考图特征：黑色中长发、深绿色宽松高领毛衣、黑色宽松长裤或半身时可见高领毛衣。
- 绿毛衣女孩承担核心动作，不只是装饰。
- 不是参考图多视角设定稿排版。
- 画面怪诞、有创意、有意思。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读。
- 橙色只用于主路径或箭头。
- 红色只用于重点、问题、提醒或结果。
- 蓝色只用于补充说明、反馈或系统状态。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有“常见坑 / Workflow / 系统架构图 / 路线图”等标题。
- 角色变成黑色怪物、吉祥物、表情包或可爱卡通。
- 角色不像参考图：发型、深绿色高领毛衣、黑色宽松长裤或整体气质偏离太多。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板，没有荒诞隐喻。
- 直接复刻 `assets/ip-reference.png` 的多视图设定图排版。

## 迭代方法

- 太普通：让绿毛衣女孩成为动作主体，加入一个奇怪但成立的隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 太可爱：强调 restrained, calm, not chibi, not mascot, not children's illustration。
- 太不像 IP：强调 black medium-length hair, dark green oversized turtleneck sweater, black loose pants, white sneakers。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成手绘场景。
- 太像设定图：保留角色外观，换成单一正文隐喻场景。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。

## 交付判断

高质量图应该让读者先觉得“有点怪”，然后 1 秒内看懂结构。

如果第一眼像教程页，而不是白纸上的怪诞产品草图，就不合格。
